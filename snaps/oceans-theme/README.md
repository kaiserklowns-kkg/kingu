# Oceans Theme

Two color themes for Kingu in deep-sea blues, named after Oceans OS:

- **Oceans Dark**: navy chrome, a teal accent and calm token colors.
- **Oceans Light**: the same palette on a pale sea-glass background.

Both build on VS Code's Dark Modern and Light Modern, so every color they don't set looks the
way you expect.

## Use it

Install the snap, then pick a theme in **Settings › Appearance** or with
**Preferences: Color Theme**. Themes are data only: this snap runs nothing and asks for no
permissions.
