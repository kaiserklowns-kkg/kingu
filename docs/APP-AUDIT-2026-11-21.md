## Findings

### P1 — Windows permission hold ยังไม่ยืนยัน

`apps/desktop/src-tauri/src/agent/hooks.rs:118` ใช้ script `#!/bin/sh` และ `hooks.rs:155` hardcode command เป็น `/bin/sh ...`

ผลกระทบ: บน Windows ที่ไม่มี `/bin/sh` (เช่น ไม่ได้ใช้ Git Bash) permission hold ของ Claude อาจไม่ทำงาน ทำให้ card ไม่ขึ้น "needs you" และปุ่ม Allow/Deny ใช้ไม่ได้

สถานะ: CI มี Windows build แต่ไม่ได้แปลว่า hook runtime ทำงาน ต้องทดสอบบน Windows จริงหรือทำ script แบบ cross-platform

### P1 — Docs parity stale ทำให้อ่านสถานะผิด

- `docs/ADE-PARITY.md:62` บอก Approve/deny ยังไม่มี blocking hook answer แต่โค้ดมี `PERMISSION_HOLD_SCRIPT` แล้ว
- `docs/ADE-PARITY.md:69` บอก Dashboard ยังไม่มี project filter แต่บันทึกท้ายไฟล์บรรทัด 164 ยืนยันว่ามีแล้ว
- `docs/SNAP-DESIGN.md` §11 ยังติ๊ก很多事情ว่าขาดทั้งที่ทำแล้ว

ผลกระทบ: คนอ่าน docs จะประเมิน gap สูงเกินจริงและอาจทำงานซ้ำ

### P2 — SSO cookie อายุ 30 วัน แต่ token อายุ 12 ชั่วโมง

- `apps/web/src/lib/server/api.ts:23` ตั้ง cookie `maxAge` 30 วัน
- `apps/server/internal/api/oidc.go:62` ตั้ง `SessionTokenTTL = 12 * time.Hour`

ผลกระทบ: หลัง 12 ชั่วโมง cookie ยังอยู่แต่ API จะตอบ 401 ผู้ใช้ถูกพาไป login ใหม่ ไม่ใช่ช่องโหว่ แต่ควรตั้ง cookie ตามอายุ token หรือยอมรับว่า SSO ต้อง re-login ทุก 12 ชั่วโมง

### P2 — Team server ยังเป็น single-org

`apps/server/README.md:413` ระบุ TODO:

- OIDC หลาย org บน server เดียว
- auto-join พร้อม default role
- create/delete org ผ่าน API

ปัจจุบันสร้าง org ผ่าน CLI `-create-org` เท่านั้น

### P2 — ADE ยังขาด P1 default chords

`docs/ADE-PARITY.md:126` ระบุว่ายังขาด:

- `⌘N` new worktree
- `⌥⌘←/→` worktree history
- browser back / forward / address chords

### P2 — Deploy และ external IdP ยังไม่เคยรันจริง

ตรวจได้แค่ compose config และ web production build ยังไม่ได้พิสูจน์ว่า:

- Docker images build ได้
- PostgreSQL init/migrations ทำงานกับ volume จริง
- Caddy ออก TLS และ forward headers ถูก
- OIDC กับ IdP จริง (Google/Entra/Keycloak) ทำงานครบ flow
- SSE ผ่าน Caddy/Web ไม่มี buffering หรือ timeout

- Review N Branches หลัง bulk delete

### P3 — เอกสารและภาพประกอบเก่า

## ความเสี่ยงที่ยังเหลือ

1. **Runtime ไม่เคยถูกทดสอบในรอบนี้** — test ผ่าน不代表แอปเปิดได้จริง
2. **Windows hooks** — เสี่ยงที่สุดถ้าผู้ใช้ Windows
3. **Deploy stack** — config ถูกแต่ยังไม่เคยขึ้นจริง
4. **OIDC ภายนอก** — ยังไม่เคยแลก token กับ IdP จริง
5. **Horizontal scaling** — ยังไม่ได้ตรวจ rate limit, SSE และ trusted proxy เมื่อมี API หลาย replica
